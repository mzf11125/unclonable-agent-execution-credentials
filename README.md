# Unclonable Agent Execution Credentials

Reference implementation of **ERC-8380**, a minimal Guard primitive that
verifies a zero-knowledge proof and burns a nullifier at most once, as part of
performing the action the capability authorized.

## Status

Draft, submitted as [ethereum/ERCs#1953](https://github.com/ethereum/ERCs/pull/1953)
(reassigned number 8380). See [SPEC.md](./SPEC.md) for the working spec and
the discussion log, and [`erc/`](./erc/) for the submission ready proposal.

The normative Guard is
[`CoupledCredentialGuard`](./src/CoupledCredentialGuard.sol). Issuance is
mandatory and the burn is fused to the authorized call.
[`UnclonableCredentialGuard`](./src/UnclonableCredentialGuard.sol) is the earlier
separable form, kept only so the adversarial suite can exhibit the liveness break
that motivated the change.

## Toolchain

- [Foundry](https://book.getfoundry.sh/) 1.5.1+
- [Noir](https://noir-lang.org/) `bb` 5.0.0-nightly, `nargo` 1.0.0-beta.21+

## Setup

```bash
# Install dependencies
forge install

# Build Solidity
forge build

# Run Solidity tests
forge test

# Compile Noir circuit
cd noir/nullifier
nargo compile
```
