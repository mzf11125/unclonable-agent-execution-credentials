# Unclonable Agent Execution Credentials

Reference implementation of **ERC-XXXX** — a minimal Guard primitive that
verifies a zero-knowledge proof and burns a nullifier exactly once.

## Status

Draft — pre-implementation. No ERC number assigned. See [SPEC.md](./SPEC.md).

## Toolchain

- [Foundry](https://book.getfoundry.sh/) 1.5.1+
- [Noir](https://noir-lang.org/) `bb` 5.0.0-nightly, `nargo` 1.0.0-beta.21+

## Setup

```bash
# Install dependencies
forge install

# Build Solidity
forge build

# Run Solidity tests
forge test

# Compile Noir circuit
cd noir/nullifier
nargo compile
```
